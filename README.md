# Animalia Website

The **Animalia** website is the official online platform for the **Animalia** animated series. It provides a look into the series' story, characters, updates, and media content.

## Key Features

- **Story Overview**: Learn about the world, themes, and setup of the series.
- **Character Pages**: Explore detailed character profiles with alternating aesthetics tailored to each character.
- **News Updates**: Announcements and community highlights, such as game releases and fan contributions.
- **Media Page**: A grid-based layout showcasing the latest posts and behind-the-scenes content.
